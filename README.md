# Mousetrap Trainer

読む、理解する、声にする。英語劇の台本学習・セリフ暗記アプリ。

公開先: https://mousetrap-trainer-ibuki.ibukioike2009.chatgpt.site

## はじめる

公開版には、このアプリ用に作成したオリジナル練習台本だけを収録しています。The Mousetrapの本文・翻訳は公開していません。

1. ホームの「台本を読み込む」を開く。
2. 保有するバックアップZIP、または5種類のJSONをまとめて選択する。統合JSONにも対応。
3. 発話数などを確認し、「この台本を使う」を押す。
4. 自分の役を選び、読む／稽古を始める。

データは端末内で処理・保存します。アカウント登録・サーバーへの台本送信は不要です。

## 機能

- ホーム、役選択、場面、進捗、続きから読む／稽古再開。
- 連続スクロール台本、熟語の最長一致辞書、日本語訳・文法・重要表現の解析シート、原文ト書き、解釈・演技メモ。
- 発話検索、話者・要復習フィルター、幕・場面の切り替え。
- 右スワイプで未着手→練習中→暗記済み、左スワイプで要復習。ボタンでも操作でき、直後に取り消せる。
- 下部中央のスクロールスティック。倒し具合で速度が変わり、同方向へ短く2回倒すと次／前の自分のセリフへ。隣のボタンでも移動可能。
- 台本穴埋め。相手のセリフを読み、自分のセリフを思い出す。正解表示→次へ。前の発話に戻ると再び隠す。
- 音声稽古。相手役を再生し、自分の番で停止。音声未登録・再生失敗時は案内と手動進行を提供。
- 範囲指定、学習状態、要復習、閲覧位置と稽古の続き、バックアップ保存・復元、文字サイズ・行間・速度設定。
- オフライン用アプリキャッシュ、PWAインストール、更新確認。音声認識は実装対象外。

## 音声を追加

「設定 → 録音ファイル → 音声を追加」で `発話ID.mp3` などの音声を選択します。任意名や1つの録音を区切って使う方法は [docs/audio.md](docs/audio.md) を参照してください。録音本体は未収録です。

## 開発と検証

Node.js 22以降。実行時依存パッケージなし。

```sh
npm test
npm run build
python3 -m http.server 8080 --directory dist
```

実際の私有バックアップを含めて検証する場合（私有ファイルをリポジトリに置かないこと）:

```sh
PRIVATE_ZIP=/absolute/path/to/backup.zip npm test
```

[構成・データ](docs/architecture.md) / [検証記録と制約](docs/qa.md)

台本と録音の権利は各権利者に帰属します。配布権限のあるデータだけを使用してください。
