# Mousetrap Trainer

読む、理解する、声にする。英語劇の台本学習・セリフ暗記アプリ。

公開先（GitHub Pages）: https://totoro0419.github.io/mousetraptrainer/

## はじめる

The Mousetrapの提供済みデータ（1,164発話・3場面・日本語訳・語彙・文法・辞書・補完ト書き）を `dist/data/mousetrap.json` に収録しています。開くと自動で本編を読み込みます。ファイルの選択は不要です。

1. ホームの「担当する役」を押し、一覧から担当する役を選んで「この役にする」を押す。ホームの選択欄からも変更できます。
2. 「台本を読む」または「練習を始める」を押す。

旧版でサンプルだけを使っていた場合も自動で本編へ移ります。同じデータID・発話IDの学習状態、閲覧位置、稽古の続き、録音の対応は維持します。自分で読み込んだ別の台本は切り替えません。別データの読み込みやバックアップの復元は引き続き利用できます。

データは端末内で処理・保存します。アカウント登録・サーバーへの台本送信は不要です。

## 機能

- ホーム、役選択、場面、進捗、続きから読む／稽古再開。
- 横幅いっぱいの発話を薄い仕切り線で区切る連続台本。自分のセリフは淡い青で強調。単語・熟語をタップすると辞書、発話の背景や辞書対象外の本文をタップすると解析シートを開きます。各発話には独立した栞ボタンがあり、栞を付けたセリフだけに絞り込めます。復習マークとは別に端末へ保存します。
- 発話検索、話者・要復習フィルター、幕・場面の切り替え。
- 右スワイプで未着手→練習中→暗記済み、左スワイプで要復習。ボタンでも操作でき、直後に取り消せる。
- 下部中央の半透明な円でスクロール。倒し具合で速度が変わり、同方向へ短く2回倒すと次／前の自分のセリフへ。ボタンでの移動は幕・場面メニュー内に収納。
- 台本穴埋め。相手のセリフを読み、自分のセリフを思い出す。正解表示→次へ。前の発話に戻ると再び隠す。
- 音声練習。全1,164セリフの英語音声、相手役の再生、自分の番で停止、模範音声、速度調整・連続再生・反復。失敗時は再試行と手動進行を提供。
- 範囲指定、学習状態、要復習、閲覧位置と稽古の続き、文字サイズ・行間・速度設定。低頻度の読み込み・バックアップ・インストール・更新操作は「設定 → データとアプリ」に収納。
- オフライン用アプリキャッシュ、PWAインストール、更新確認。音声認識は実装対象外。

## セリフの解説

全1,164発話に、原作PDFと独立照合した脚本・心理・演出解説を表示します。原文・和訳の直後に基本解説を置き、背景・心理・言外の意味、伏線と真相、演技の補足は存在するものだけ表示します。関連するセリフから回収先の解説を開き、元の解説へ戻れます。**解説全体に結末の情報を含みます。**

解説は `dist/data/mousetrap-dramaturgy.ja.json` を発話IDで結合します。別の台本や同じIDを再利用した改変台本へ誤接続しないよう、全文の対応も確認します。解説の版を独立管理し、更新時も担当する役・栞・暗記状態・要復習・閲覧位置・メモを維持します。オフラインでも保存済みの解説を利用できます。

文法・語彙・辞書と確認済みの原文ト書きは引き続き表示し、自分の解釈・演技メモは別に保存します。追加台本に解説がない場合は従来の前後の発話を使う表示を保ちます。

[独立監査・34件の修正](docs/dramaturgy/independent-audit.md) / [全件判断と変更前後](docs/dramaturgy/independent-audit.json)

## 音声で学ぶ・練習する

全1,164セリフの提供済み英語MP3を収録（3場面、32.50MB、約90分16秒）。初回の音声ファイル選択は不要です。文章詳細の再生から聴き始め、速度・前後移動・連続再生を必要に応じて展開できます。台本にはセリフごとの再生ボタンを増やさず、再生中の行を強調します。手動でスクロールすると自動追従を解除します。

台本上部の練習ボタン、ホーム、文章詳細の「ここから練習する」から共通ボトムシートを開きます。音声練習は相手役を再生し、自分の番で停止。正解の表示・非表示、模範音声、範囲反復、自分の発話時間の余裕、自動進行を設定できます。穴埋め練習も同じシートで利用できます。文章詳細・辞書はその上で開き、戻ると練習位置と音声位置を維持します。再読み込み後は「続き」から明示的に再開します。

音声は必要なものと次の1件だけ読み込みます。PWAでは利用した音声を最大40件保存し、保存済み分をオフライン再生します。未取得の全音声をオフラインで使えるという意味ではありません。自分で登録した録音は同梱音声より優先します。

「設定 → 音声を追加」の既存機能も維持しています。[音声・検証根拠・制約](docs/audio.md) / [統合の検証記録](docs/audio-integration-qa.md)

## 開発と検証

Node.js 22以降。実行時依存パッケージなし。

```sh
npm test
npm run build
python3 -m http.server 8080 --directory dist
```

元の提供ZIPとの回帰検査も行う場合:

```sh
PRIVATE_ZIP=/absolute/path/to/backup.zip npm test
```

[構成・データ](docs/architecture.md) / [検証記録と制約](docs/qa.md)

台本と録音の権利は各権利者に帰属します。データの由来・公開方針は [docs/data-source.md](docs/data-source.md) を参照してください。

## GitHub Pagesへの公開

`main` へのpushで `.github/workflows/pages.yml` がテスト・ビルドを行い、`dist/` をGitHub Pagesに公開します。Pagesの公開元はGitHub Actionsを使用します。
