## 既存データと表示の扱い

元の `mousetrap.json` はSHA-256 `022dc48dd68c85773e9ce8307a7d3f1e2a3bceafc20a4a9b8db83e472a81a7b6` のまま。監査済み解説のSHA-256も `492b0822db008d4cb126f87410701a74146660bc991abfd8b42b9b302c5cbc39` のまま。統合PRは内容監査後の文章を変更していない。

説明を読む順は原文・訳→基本解説→任意補足→伏線・関連先→演技・元のト書き→自分のメモ→文法・語彙・学習状態。既存のmodal dialog、details、色・余白を使い、追加の確認画面を置かない。解説全体がネタバレを含むことはREADMEへ記載し、spoiler欄だけで判定しない。
