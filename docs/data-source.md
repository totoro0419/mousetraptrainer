# 収録データの由来

- 作品: The Mousetrap / Agatha Christie。
- 本編JSON: このプロジェクトで利用者が提供した台本・日本語訳・語彙・文法・辞書のバックアップを統合したもの。
- ト書き: 利用者が提供した台本PDFと話者・発話本文が一意に一致する箇所から対応付け。曖昧な箇所は推測で補わない。
- ファイル: `dist/data/mousetrap.json`。1,164発話、3場面、初期辞書578項目、追加辞書1,143見出し語（前回843見出し語＋今回厳選した300見出し語・表現）、合計1,721見出し語、ト書き450発話。追加辞書は `dist/data/dictionary-nouns.ja.json`、`dist/data/dictionary-general.ja.json`、`dist/data/dictionary-next-words.ja.json`、`dist/data/dictionary-next-expressions.ja.json` に格納。今回の300見出し語・表現は本編発話内で表記の出現を独立確認済み。基本語義と劇中での厳密な意味は区別して表示し、元の辞書項目は上書きしない。
- 公開方針: 2026-10-30に利用者から、著作権上の問題はないとの申告と、JSONをGitHubに収録してアプリへ接続する明示的な指示を受け、同梱方式へ変更した。

## ト書き日本語要約（2026-11-05）

- 対象は既存の発話IDに結び付いていたト書き450件（第1幕第1場93件、第1幕第2場142件、第2幕215件）。新規抽出した独立ト書きは含まない。
- `dist/data/mousetrap.json` の `directions[発話ID].ja` に、同じ `original` をもとに簡潔な日本語要約を整備した。長い原文は重要な登退場・動作・音響・小道具を優先して要約している。
- 照合用の全450件の要約は `dist/data/mousetrap-directions-ja.json` にも保存。原文・出典・照合フラグ・タイミング注記・セリフIDは維持している。
- 機械検査では450件のキー一致、空欄なし、発話ID存在、原文保持を確認。日本語要約の全件について原作PDFとの独立した逐語照合が完了したという意味ではない。
- **配置上の注意:** 既存の一つの `original` には、発話時の指示と「その発話の後から次の発話まで」の動作が併記されている場合がある。今後の台本UIで全要約を無条件に「発話の直前」に配置することはせず、時系列を検証して扱う。
