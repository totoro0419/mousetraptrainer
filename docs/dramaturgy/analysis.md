対象は提供PDF（84ページ、印刷本文1–83ページ）と、main `0ed8e3375ccbd87de3f639bb82746a91e62a4518` の統合JSON。PDFを冒頭から結末まで通読してから個別解説を制作した。一般的な別版のあらすじより、この提供版を優先する。以下の短縮表記 A/B/C はそれぞれ act1-scene1 / act1-scene2 / act2 の speech 番号を表す。

## 資料と対応

- `dist/data/mousetrap.json`: script 1,164（190 / 336 / 638）、translations / vocabulary / grammar 各1,164、dictionary 578、directions 450。一意ID・補助データの孤立IDゼロを再計算。
- 翻訳・文法・語彙・辞書は独立ファイルではなく統合JSON内に存在。各発話へ結合した参照用JSONLを作業領域に用意。解説はそれらの文章の流用ではなく、英文・ト書き・前後関係から記述する。
- 450件のdirections以外にもPDFに動作がある。directionsの不在は「ト書きなし」を意味しない。また既存のdirectionには次の発話前の動作も含まれ、直前の発話の言い方とは限らない。
- 既存データの既知の文法説明不整合は今回の校訂対象外。原文JSONも変更しない。

## 人物の知識・目的の推移

- **モリー**: 開業を成功させたい。子供たちの学校の元教師で、ジミーの救助の手紙を肺炎のため当時読めず、死後に読んだ悔恨を隠す（C577–584、609–611）。B218の否認はこの過去を伏せる。ケースウェルの姉という正体やトロッターの偽装は知らない。C243の不信は夫についての暗示から生まれる。ロンドン行きは夫への葉巻購入（C623–625）。同情を恋愛関係と確定しない。
- **ジャイルズ**: 妻と宿を守りたい。クリストファーへの反感に、外見への偏見・嫉妬・殺人への恐怖が重なる。切符を拾って妻の隠し事を疑う（B327直後のト書き、C282）。自分もロンドンへ帽子を買いに行ったが驚かせるため伏せる（C622、630）。妻の教師時代の事情は結末まで聞いていない。
- **クリストファー**: 無邪気・不穏な冗談で注目を集め、ボイルをからかう。偽名で建築家も虚偽、兵役脱走を隠すが、殺人犯ではない（C197–206、587–589）。母を失い保護を求める心理は本人の言葉で支えられる。残酷な冗談と実際の犯罪を区別。モリーの手紙の具体的事情までは聞いていない。
- **ケースウェル／キャシー**: 虐待された三人きょうだいの姉。海外で暮らし弟を捜して帰英（C600）。B231の無関係の主張は虚偽だが、当初からトロッターを弟と認識しているのではない。C450–455の髪をねじる癖で気づき、C489–493で動揺し、その後メトカーフ役の警官に相談（C618）。姉弟の具体的な幼少期の記憶で絞殺を止める（C594–602）。医療観への反発は彼女の態度として記述し、医学的事実に一般化しない。
- **トロッター／ジョージー**: 弟ジミーの死をめぐり復讐を実行する。スタニング夫人・ボイルを殺し、モリーを第三の標的にする。公衆電話から警察を名乗り、玄関へ来る前に線を切った（C587）。警官としての「知らない」「保護する」は偽装。事件の過去を知るが、姉の現在の姿・所在は直ちには認識しない。C434や488は認識に近づく反応として読めるが、正確な確信の瞬間を新しく断定しない。C589から児童的口調がト書きで明示される。診断語は彼の供述・劇中人物の見立てとして扱い、実在の病気と暴力を結びつけない。
- **メトカーフ役の人物**: 本当の警官。本物の少佐の了承を得て予約を代わった（C614–616）。最初から偽警官の登場を不審に思うが、いつ殺人犯と確定したかは明示されない。「警察」への驚き（B139）は捜査の予定と違う人物が来るためと読める。スキーを四柱ベッドの上に隠す（C618）。捜索や地下室の探索には身分を伏せた捜査としての読みが可能。ただし全ての行動を台本で明示された捜査手順と断言しない。
- **ボイル**: 快適さと社会的権威を要求する。かつて子供の農場への委託に関わった治安判事（B253–258）。自分の判断を礼儀正しい里親と報告で正当化し、責任を認めたがらない。殺害前に来訪者を見て安心する（B335）のは、後に偽警官と判明する人物への信頼と結びつく。彼女が殺人を計画していた等の追加設定はない。
- **パラヴィチーニ**: 正体不明を楽しみ、相手を不安にさせる。化粧・年齢・行き先・商売を伏せ、犯人への疑いを引き受けるミスリード。C620の時計千個や隠し場所はジャイルズの推量で、押収された事実ではない。正確な年齢・職業・荷物の中身を確定しない。事件の真相を最初から知る共犯者としない。

## 留保・原データ上の注意

1. C110の「三人の男の子」は、B187の「男児二人と女児一人」と食い違う。モリーの発話／収録本文の不整合として注記し、三兄弟という設定を作らない。
2. 兄の年齢はB211で約22、C95で23と言われる。概数・発話差であり一歳を使った独自の時系列確定をしない。
3. B308のtextに `{He moves above the sofa table.)` が混入。PDFでは動作。原データは保持し、その文字列を話者が発声するセリフとして分析しない。
4. B121の「今朝」は場面指定「翌日午後」と一致しない。原文の発話として残し、別の朝の場面を作らない。
5. モリーが挙げる父の捕虜歴・心理・復讐（C128）は仮説。子供の父が帰還して復讐した確定事実ではない。
6. 偽警官の捜査・医学・法に関する断言は、権威ある外部事実の資料として使わない。A/Bの宿泊拒否の法的説明もモリーの主張として扱う。
7. 家の見回り・動線は台本の複数階段と地下の経路を踏まえる。全員を同じ階段に置かず、物音だけで犯人を確定しない。

8. C371の否定形の問いは直前の確信的な発言との接続が曖昧。独自に肯定形へ直さず、細かな発言意図は確定できないと記載する。
9. C495のRed Queenという言及は原文のまま保持する。ただし参照される「朝食前の不可能なこと六つ」は白の女王の発話。Lewis Carroll『Through the Looking-Glass』第5章の[原文](https://www.gutenberg.org/files/12/12-h/12-h.htm)で確認した（2026-10-31）。話者がわざと間違えたのか、提供版の誤りなのかは確定しない。
10. 電話線を切ったのは、ジョージーの告白では「玄関へ来る前」。窓に姿を現すより前とまで時刻を限定しない。
