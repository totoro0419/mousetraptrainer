# 脚本・心理・演出解説（日本語）

全1,164発話の独立した解説データ。結末を含む。単なる対訳ではなく、発言のきっかけ、人物の目的・心理、会話上の働き、必要な箇所の伏線と演技を記述する。

## データ

[`dist/data/mousetrap-dramaturgy.ja.json`](../../dist/data/mousetrap-dramaturgy.ja.json)

| 場面ID | 件数 |
| --- | ---: |
| act1-scene1 | 190 |
| act1-scene2 | 336 |
| act2 | 638 |
| 合計 | 1,164 |

ルートは既存の発話IDをキーとするオブジェクト。ID・格納順・場面・話者は元の `mousetrap.json` に対応する。話者・原文・訳は重複収録せず、利用側が同じIDで結合する。既存バンドルの形式や内容は変更していない。アプリの表示への組込みはこのPRの対象に含めない。

| フィールド | 型 | 収録件数 | 内容 |
| --- | --- | ---: | --- |
| explanation | string | 1,164 | 必須。発話固有の状況・意図・心理・会話への作用を統合 |
| premise | string | 34 | 読み違えやすい前提・原文上の留保 |
| cause | string | 4 | 別記する意味のある直接のきっかけ |
| emotion | string | 18 | 表に出す態度と内心など、重要な心理の補足 |
| intention | string | 13 | 相手に対する具体的な働きかけ |
| subtext | string | 12 | 言わない目的・言外の意味 |
| devices | string[] | 97 | 実際に認められる皮肉・嘘・挑発・ユーモアなど |
| spoiler | string | 52 | 別場面での回収や真相との対応の補足 |
| acting | string | 49 | ト書き、間、声、視線、相手との距離に基づく示唆 |
| relatedLineIds | string[] | 243 | 根拠・回収先・対応する発話への参照。計519参照 |

前提・原因・心理・意図の多くは `explanation` に統合している。任意フィールドの少なさは、その観点の分析がないことを意味しない。空フィールドや全件への定型的な分類は追加していない。

`explanation` 自体にも結末の情報を含む。`spoiler` だけを非表示にしてもネタバレは除去できない。

## 読み方と根拠

- 場面中の事実と、登場人物の自己申告・嘘・推量を分ける。後に分かる事実を、その時点の人物の知識にしない。
- 心理・演技は本文と動作に基づく分析。「読める」「可能」「明示されない」等の留保を使い、一つしかない作者の正解とは扱わない。
- 重大な真相・手がかりは参照IDで回収先を示す。参照は必ずしも後の発話だけではなく、直前の原因や前場の対応箇所も含む。
- 疑いを持つ言葉と、実際に犯行を実行したことは区別する。特にレンのスキー盗難案、父の復讐説、パラヴィチーニの時計の話は混同しない。

## 検証

```sh
node scripts/validate-dramaturgy.mjs
npm test
npm run build
```

PDFの原本を用意した場合:

```sh
python3 scripts/verify-dramaturgy-source.py --pdf /path/to/The-Mousetrap.pdf
```

PDF比較にはPopplerの `pdftotext` が必要。提供版のSHA-256を照合して版違いを検出する。句読点と空白を除き英数字を正規化し、全発話の話者順と本文を確認する。四つの非括弧の場面説明は、明示した本文と一致する場合にのみ分離する。4区間を無条件で照合対象から除外する方式ではない。

機械検査の記録は [validation.json](validation.json)、PDFとの照合は [source-validation.json](source-validation.json)。これらは構造・参照・文字列の検査であり、心理解釈を自動的に正解と認定するものではない。

検査スクリプトは既存訳との完全同文、同一解説の反復、特定の空疎な定型文も検出する。ただし言い換えによる水増しや文脈上の誤読を完全に機械判定はできないため、内容は別に照合した。
