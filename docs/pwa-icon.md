# PWA icon design and verification

## Specification

- Browser/Web Manifest: `icons` entries must identify the correct pixel dimensions and valid PNG MIME types; `purpose: "any"` and `purpose: "maskable"` are separate contexts.
- W3C Web App Manifest maskable safe zone: a central circle with radius 40% of the full icon size. Important art must remain readable inside that safe zone; the background must be full bleed so arbitrary Android masks never reveal a rectangular tile behind the shape.
- Chrome icon updates: change icon URLs when updating the installed PWA. The versioned `icon-v2-*.png` filenames are intentional.
- Do not bake rounded-corner tiles, outer rings, drop shadows around the whole icon square, or extra OS masks into the source image. The OS applies the final shape.

## Approved visual

- Open book / script under a luminous theatrical stage.
- Cool white/light-blue background with blue stage and warm central light; matches the site's luminous minimalism UI.
- No quotation marks and no concentric rounded-square card.
- Regular source: `assets/pwa-icon-regular-v2.webp` (512x512 RGB).
- Maskable source: `assets/pwa-icon-maskable-v2.webp` (512x512 RGB, centrally scaled stage, continuous full-bleed background).
- Published output: `dist/icon-v2-192.png`, `dist/icon-v2-512.png`, `dist/icon-v2-maskable-512.png`. Keep original dimensions; resize 192 from 512 with a high-quality filter. Never enlarge a 192px image to 512px.

## Verification performed

- Both source WebP assets were independently SHA-matched after GitHub upload.
- Circle, rounded-square and unmasked previews were reviewed; there is no extra inner rounded-square tile.
- All 3 production PNG files were generated by GitHub Actions; automated tests validate PNG signatures, 192/512 dimensions, cache manifest refs, and structural integrity.
- GitHub Pages publishing was successful at the icon-generation stage. Device-home-screen verification is still required on the actual launcher; Android masks differ between manufacturers.
- If an already-installed app displays an old icon, Chrome can require an app identity update or reinstall. A new URL is necessary but does not guarantee the exact time an existing Android launcher updates.
