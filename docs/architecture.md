# 構成とデータ

ビルド不要のES Modules。外部CDN・フォント・実行時依存パッケージ・通信APIはありません。静的ファイルのみで任意のサブパスへ配置できます。

- `data.js`: ZIP/JSON読み込み、正規化、ID照合、検索、熟語の最長一致、進捗計算。
- `bundled.js`: 同梱本編の自動読み込み、旧版サンプルからの移行、版管理と失敗時の保存済みデータ維持。
- `storage.js`: IndexedDBの台本・音声、トランザクション。小さな進捗と設定はlocalStorageへ即時保存。
- `dramaturgy.js`: 全文照合による同梱台本への結合、解説の独立版管理、保存・更新・失敗時の維持。学習記録のキーには書き込まない。
- `reader.js`: 連続台本、辞書・解析・ト書き、横スワイプ、IDと相対オフセットによる位置復元。
- `stick.js`: 速度制御、短い往復操作の検出、長押しと2回操作の分離。
- `session.js`: UIから独立した稽古の状態遷移と範囲選択。
- `audio.js`: ローカル音声の対応付けとプレーヤー。停止後の古いコールバックは無効化。
- `rehearsal.js`: 穴埋め／音声稽古、前へ・正解表示・次へ・再開。
- `sw.js`: アプリ本体と同梱本編JSONをキャッシュ。利用者が個別に読み込んだデータはIndexedDBに保存し、サーバーへ送信しない。

## 長い台本

比較した方式は (1) 全発話の単純DOM、(2) 可変高のwindowing、(3) 全IDを安定したDOMに維持して `content-visibility:auto` と表示範囲の単語だけを遅延分割する方式。3を採用しました。2は長文の高さ推定と辞書を閉じた後の位置維持・ブラウザー内検索・大きなジャンプの複雑性を増やします。3は画面外のレイアウト・描画を省き、発話の実体を残します。未表示発話に単語ごとのボタンを作らず、IntersectionObserverで必要時のみ作ります。スクロール処理は可視発話だけを調べます。

## 同梱データと追加読み込み

The Mousetrap本編の提供済み統合データを `dist/data/mousetrap.json` に収録し、起動時に自動でIndexedDBへ保存します。初回の手動読み込みは不要です。旧版の既定サンプルからは自動移行します。旧版のサンプル選択は、版管理マーカーの有無にかかわらず本編へ移行します。別の実台本を読み込んで選択した場合は維持します。データの保存・一覧追加・初期選択は1つのトランザクションで行い、初回データの取得に失敗した場合はサンプルで代替せず再試行を案内します。

公開アプリには本編だけを収録し、サンプルJSONと切り替え操作は削除しました。テスト用の短いオリジナル台本は配信対象外の tests/fixtures/ にだけ置きます。`台本を読み込む` からバックアップZIP、5種類のJSONをまとめて、または統合JSONを追加で読み込めます。ZIPに含まれる検証レポートは台本として扱いません。

提供データの照合値: 1,164発話、3場面（190 / 336 / 638）、重複IDなし、翻訳・語彙・文法の対応は各1,164件、辞書578件。既存の学習用解説の内容自体を全件校訂したという意味ではありません。

元PDFと話者・正規化発話が一意に完全一致した1,007発話を確認し、うち450発話に原文の角括弧ト書きを対応付けました。短い日本語の確実な訳は62件。残りは詳細原文を参照でき、対応が曖昧な157発話は補完していません。原文の演技指示と利用者の解釈メモは別に表示します。出典と対応方法は同梱統合データ内にも残します。

データ更新では同じデータID・発話IDに対応する学習記録を維持します。サンプルと本編・追加台本の記録は分離します。バックアップには台本、進捗、設定、読書位置、稽古の続きを含みます。復元時の進捗は発話単位の更新日時で新しい方を採用します。音声は含みません。

## 解説サイドカー

`dramaturgy:mousetrap-private` に版と解説を保存。起動・保存台本への切替・バックアップ復元時に読み込む。元の統合JSONとIDは不変。ID・話者・原文のSHA-256で対応する版を確認し、取得した解説の内容ハッシュも照合する。異なる内容の追加台本へIDだけで結合しない。

Service Worker v7は解説JSONと読み込みモジュールも事前保存し、オンラインではnetwork-firstで更新する。更新失敗時は検証できた保存済みの解説を維持して案内し、未取得なら台本の利用を続けられる。JSON更新時は読み込みモジュールの版・内容ハッシュも更新する。ビルドと回帰検査で不一致を拒否する。

解析シートでは基本解説を優先し、任意補足を小さなdetailsで開く。元の前後和訳の機械的再掲は、解説を持たない追加台本だけのフォールバック。解説中の関連IDは全台本から解決し、現在の場面フィルターの外でも正しい解説へ移動する。本文表示・学習記録とは別に扱い、関連先を読んでも元の閲覧位置を動かさない。
